# Bundled canvas fonts

Lora, Poppins, Bebas Neue and Orelega One are distributed under the SIL Open Font License. Each family directory includes its upstream OFL.txt. Fonts are bundled with the application and served from its own origin.

Source: Google Fonts repository, https://github.com/google/fonts/tree/main/ofl (retrieved 2026-09-28).

- Lora: https://github.com/google/fonts/tree/main/ofl/lora
- Poppins: https://github.com/google/fonts/tree/main/ofl/poppins
- Bebas Neue: https://github.com/google/fonts/tree/main/ofl/bebasneue
- Orelega One: https://github.com/google/fonts/tree/main/ofl/orelegaone

Inter and Kalam remain supplied by the pinned theme package with their upstream licenses.
