# Preserve native mind-map behavior

User-reported gaps: pressing Enter on a selected node changes formatting; selected-node Duplicate and clipboard paste produce detached free shapes; a locked node cannot be unlocked after selection is lost.

Approved branch semantics: copy the selected node and its entire descendant branch. Duplicate creates a sibling branch. Paste attaches beneath the currently selected node. Duplicating a root or pasting onto empty canvas forms an independent mind map; preserve existing whole-map copying.

1. Reproduce text-editor style changes with actual UI; retain explicit typography through entry, commit, cancel and subsequent hierarchy layout. Preserve approved creation shortcuts.
2. Add topology-aware node/subtree duplication and clipboard routes with fresh identities, full descendants, style/collapse preservation, undo, source isolation and current-host guards. Cover native toolbar, custom menu and keyboard paths.
3. Keep object context access mounted independently of selection so visible locked topics can be reached by right-click and unlocked after deselection. Preserve lock edit protection and hidden-topic exclusion.
4. Validate dedicated RED/GREEN regressions, existing mind-map copy/formatting/keyboard tests and ordinary canvas/menu regressions. Review source and run static checks/build. Record exact limits and retain user acceptance gate.

Ownership: typography and copy are independent executor tasks; root owns lock/menu lifecycle and planning. Shared files require scoped coordination. Tests use synthetic boards; private screenshots and deployment data remain outside repository content.
