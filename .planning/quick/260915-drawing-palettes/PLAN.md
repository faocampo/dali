# Application menu and drawing palettes

User request: consolidate board utilities in the Dalí menu with File, View, Edit, Settings, Help; offer basic shape and line selectors.

- Retain the consolidated File/View/Help actions and inline board title.
- Edit exposes document Undo and Redo; Settings controls persistent viewport-control visibility.
- Shapes offers the native rectangle, rounded rectangle, ellipse, triangle, and diamond tools.
- Lines offers straight, curved, and angled geometry, each with plain or arrow endpoints, retaining native object attachment.
- Support keyboard operation, outside dismissal, and small viewports.
- Additional stars, arrows, and polygons require a decision between full shape support and grouped outlines; implementation remains pending that decision.
- Validate actual created models, history, endpoint styles, keyboard/focus behavior, and existing editing/export workflows.
