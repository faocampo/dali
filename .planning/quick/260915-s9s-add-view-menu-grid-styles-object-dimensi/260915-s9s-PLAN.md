# View grid, distances and dimensions

User requested implementation in Dalí → View, using a supplied menu image as a visual reference. Earlier SEED-001/002/004 provide generic behavior context. Keep the reference image outside repository content. Phase 2 remains user-approved; Phase 3 sequencing is unchanged.

## Defaults and boundaries

- Grid submenu: Off, Dots (default), Lines; base spacing 20 (default), 40 or 80 canvas pixels. Grid stays anchored to canvas coordinates, adapts density at distant zoom, and never changes object geometry.
- Object dimensions and Distances: separate off-by-default switches with icons and explicit state. Selected bounds supply dimensions. Up to four nearby axis gaps are measured in canvas pixels, within 160 screen pixels; guides update on selection, movement, resize and viewport changes. Exclude hidden content, selected descendants/containers and offscreen neighbors.
- Preferences are local to this browser, survive reload, and tolerate unavailable/malformed storage. Overlays do not enter board documents, clipboard or image exports.
- Existing native alignment behavior is retained. Additional snap-to-grid and alignment modes from the seeds remain separate follow-ups.
- Keyboard-accessible menus retain arrow/Home/End/Escape behavior; the Grid submenu uses the same column for narrow screens.
