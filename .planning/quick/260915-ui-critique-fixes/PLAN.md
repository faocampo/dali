# Canvas critique fixes

Approved scope: all five findings from the canvas critique, in priority order: keyboard/accessibility, export flow, toolbar organization.

1. Contain Export keyboard focus, retain Escape and trigger restoration, and name viewport controls.
2. Keep dimensions and Download in a stable footer, simplify settings, replace misleading sharing/promotion with artifact status, and preserve upstream attribution in Help.
3. Separate creation tools, board operations, and viewport/history; use consistent SVG icons and expose a concise shortcut guide.
4. Verify static types, unit regressions, affected browser workflows, and desktop/narrow layout. Record actual limitations without advancing Phase 2 acceptance.

The existing visual identity and approved future branding stage remain authoritative. All fixtures and documentation use synthetic or organization-neutral content.
